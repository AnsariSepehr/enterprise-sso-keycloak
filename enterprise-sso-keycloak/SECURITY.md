# Security policy

This repository contains documentation, templates and scripts, **no live secrets and no real hostnames**. If you find a real credential, hostname or IP in any file or in the git history, please open a private security advisory (or contact the maintainer) instead of a public issue, so it can be rotated and scrubbed.

The scripts change system configuration (SELinux boolean, firewall, services). Read them before running; they are provided without warranty (see LICENSE).
